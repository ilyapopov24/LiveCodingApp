## Поток данных

```
1. Пользователь вводит сообщение
   ↓
2. MCPChatFragment отправляет в ViewModel
   ↓
3. MCPChatViewModel вызывает sendMessage()
   ↓
4. MCPService анализирует контекст и выбирает сервер
   ↓
5. MCPService отправляет HTTP запрос на выбранный сервер
   ↓
6. MCP сервер обрабатывает запрос и возвращает ответ
   ↓
7. MCPService парсит ответ и возвращает MCPResponse
   ↓
8. MCPRepositoryImpl конвертирует в MCPChatMessage
   ↓
9. MCPChatViewModel добавляет сообщение в список
   ↓
10. MCPChatFragment обновляет UI
```

## Ключевые особенности

### 1. Интеллектуальный выбор сервера
- Анализ ключевых слов в сообщении
- Контекстно-зависимый выбор
- Поддержка 7 различных MCP серверов

### 2. Реактивная архитектура
- StateFlow для управления состоянием
- Автоматическое обновление UI
- Обработка ошибок и загрузки

### 3. Модульность
- Разделение ответственности между компонентами
- Легкое добавление новых MCP серверов
- Тестируемость каждого компонента

### 4. Пользовательский опыт
- Показ выбранного сервера
- Индикаторы состояния
- Интуитивный интерфейс

## Технологии

- **Kotlin** - основной язык разработки
- **MVVM** - архитектурный паттерн
- **Hilt** - dependency injection
- **StateFlow** - реактивное программирование
- **OkHttp** - HTTP клиент
- **Retrofit** - REST API клиент
- **Room** - локальная база данных
- **Docker** - контейнеризация MCP серверов
