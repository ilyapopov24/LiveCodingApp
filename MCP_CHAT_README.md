# 🤖 Интеллектуальный MCP Chat

## Описание

Новый экран-фрагмент с чатом, который интеллектуально выбирает подходящий MCP сервер на основе контекста сообщения пользователя.

## 🚀 Возможности

### Автоматический выбор MCP сервера

Система анализирует сообщение пользователя и автоматически выбирает наиболее подходящий MCP сервер:

- **📊 GitHub Analytics** - анализ профилей, репозиториев, статистика
- **🎯 AI Advisor** - рекомендации, цели, улучшения
- **🐍 Python Runner** - выполнение Python кода
- **🦙 Ollama** - локальные LLM модели
- **🤖 Android Two-Agent** - анализ Android проектов
- **🧠 Sequential Thinking** - сложные рассуждения
- **☁️ Spaceweb** - управление VPS

### Примеры использования

| Сообщение | Выбранный сервер | Описание |
|-----------|------------------|----------|
| "Проанализируй мой GitHub профиль" | 📊 GitHub Analytics | Анализ профиля |
| "Дай рекомендации по развитию" | 🎯 AI Advisor | Рекомендации |
| "Выполни этот Python код" | 🐍 Python Runner | Выполнение кода |
| "Запусти модель llama2" | 🦙 Ollama | Локальные модели |
| "Исправь баг в Android проекте" | 🤖 Android Two-Agent | Анализ Android |
| "Думай пошагово над проблемой" | 🧠 Sequential Thinking | Сложные рассуждения |
| "Создай новый VPS сервер" | ☁️ Spaceweb | Управление VPS |

## 🏗️ Архитектура

### Компоненты

1. **MCPService** - основной сервис для работы с MCP серверами
2. **MCPChatViewModel** - управление состоянием чата
3. **MCPChatFragment** - UI фрагмент чата
4. **MCPRepositoryImpl** - репозиторий для интеграции с MCP серверами

### Поток данных

```
Пользователь → MCPChatFragment → MCPChatViewModel → MCPService → MCP сервер → Ответ
```

## 🔧 Настройка

### 1. MCP серверы

Убедитесь, что все MCP серверы запущены:

```bash
cd docker-mcp-reports
docker-compose up -d
```

### 2. Конфигурация

MCP серверы должны быть доступны по следующим URL:
- GitHub Analytics: `http://localhost:8080/mcp/github-analytics`
- AI Advisor: `http://localhost:8080/mcp/ai-advisor`
- Python Runner: `http://localhost:8080/mcp/python-runner`
- Ollama: `http://localhost:8080/mcp/ollama`
- Android Two-Agent: `http://localhost:8080/mcp/android-two-agent`
- Sequential Thinking: `http://localhost:8080/mcp/sequential-thinking`
- Spaceweb: `http://localhost:8080/mcp/spaceweb`

## 📱 Использование

### 1. Открытие чата

1. Запустите приложение
2. Перейдите на вкладку "MCP Chat" в нижней навигации
3. Нажмите "Подключиться" для подключения к MCP серверам

### 2. Отправка сообщений

1. Введите сообщение в поле ввода
2. Нажмите "Отправить"
3. Система автоматически выберет подходящий MCP сервер
4. Получите ответ от выбранного сервера

### 3. Примеры сообщений

```
# GitHub анализ
"Покажи статистику моего профиля"
"Проанализируй репозиторий LiveCodingApp"

# AI рекомендации
"Дай советы по улучшению кода"
"Поставь цели на месяц"

# Python выполнение
"Выполни: print('Hello World')"
"Запусти тесты для проекта"

# Android анализ
"Найди баги в Android проекте"
"Исправь ошибки компиляции"

# Сложные рассуждения
"Думай пошагово над архитектурой"
"Проанализируй проблему производительности"

# VPS управление
"Создай новый сервер"
"Покажи список VPS"
```

## 🎨 UI особенности

### Индикаторы

- **🤖 Выбран MCP сервер** - показывает, какой сервер был выбран
- **⏳ Обработка** - индикатор загрузки
- **✅ Успех** - успешное выполнение
- **❌ Ошибка** - ошибка выполнения

### Цветовая схема

- **Синий** - сообщения пользователя
- **Серый** - системные сообщения
- **Красный** - сообщения об ошибках
- **Зеленый** - успешные операции

## 🔍 Отладка

### Логи

Проверьте логи для отладки:

```bash
# Логи приложения
adb logcat | grep MCP

# Логи MCP серверов
docker logs mcp-github-analytics
docker logs mcp-ai-advisor
docker logs mcp-python-runner
docker logs mcp-ollama
docker logs mcp-android-two-agent
docker logs mcp-sequential-thinking
docker logs mcp-spaceweb
```

### Проблемы

1. **Сервер не выбирается** - проверьте логи MCPService
2. **Ошибка соединения** - убедитесь, что MCP серверы запущены
3. **Неправильный сервер** - проверьте логику выбора в MCPService

## 🚀 Развитие

### Добавление новых серверов

1. Добавьте новый тип в `MCPServerType`
2. Обновите логику выбора в `MCPService.selectMCPServer()`
3. Добавьте URL в `MCPService.getServerUrl()`
4. Обновите UI в `MCPChatFragment.updateMCPServerInfo()`

### Улучшение логики выбора

Можно улучшить алгоритм выбора серверов, добавив:
- Машинное обучение для более точного выбора
- Контекст предыдущих сообщений
- Пользовательские предпочтения
- Взвешенные алгоритмы
